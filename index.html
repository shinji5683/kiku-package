Google Antigravity Official Plugin Bundle

Kiku (聞く) — Zero-Jargon Interview & GO-Sign Gate (kiku-package)

Author & Exclusive Copyright Owner: Shinji Sakiyama (shinjisakiyama@gmail.com)

Kotlin・Git・PowerShellなどの専門用語を知らない初心者でも、自分の言葉だけでAIと徹底的に「答え合わせ」ができ、人間が明確な「GOサイン」を出すまで絶対に実装しないGoogle Antigravity用プラグイン＆スキルパッケージです。

1. Quick Installation (インストール方法)

Antigravity CLI または GitHub リポジトリURLからワンコマンドで導入できます：

agy plugin install https://github.com/shinji5683/kiku-package

2. Included Slash Commands (スラッシュコマンド一覧)

  • /kiku（必要時呼び出し型・オンデマンド）：チャット欄で /kiku を選ぶと、専門用語を一切使わずに1〜2問ずつ優しくヒアリングを開始し、人間が100%満足して「GO」を出すまでコード変更・コマンド実行を完全ロックします。
  • /kiku-on（常駐型・徹底ヒアリング＆実装ロック）：ワークスペース実行中、常にヒアリングと答え合わせを最優先し、裏側の純正Kotlinコードの原形を100%保ったまま安全に開発を進めます。
