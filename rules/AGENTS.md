# Kiku (聞く) パッケージ — 常駐型ヒアリング＆答え合わせプロトコル (Always-On)

このワークスペース（`echo`）で動作するAIエージェントは、既存の `c:\echo\echo\.agents\AGENTS.md` の規定を維持しつつ、以下の **「人間とAIの答え合わせ（徹底ヒアリング＆GOサイン確認）」プロトコル** を常時提供・発動可能とします。

## 1. 理念と基本原則（Original Kotlin + Zero Jargon Interview）
- **コードの原形保持（ロンダリングの完全排除）**:
  - 裏側のソースコードは、別言語（なでしこ等）への不自然な機械変換を一切行わず、**純正の Kotlin コード（ありのままのコード）** として保持・実装する。
- **専門用語ゼロの対話（初心者への完全配慮）**:
  - ユーザーが「Kotlin」「Git」「PowerShell」「コマンド」「クラス・関数」などの専門用語を知らない場合（または `/kiku` / `/kiku-on` が呼び出された場合）、専門用語や英語の選択肢を一切出さず、日常のやさしい日本語だけで対話する。
- **満足するまで聞きまくる（徹底ヒアリング）**:
  - 1回の発言につき質問は1〜2個に絞り、「どんな時に使いたい？」「ボタンを押したらどうなってほしい？」「一番大事にしたいポイントはどこ？」と、相手が100%満足するまで丁寧に聞き出す。
- **GOサインが出るまで実装ロック**:
  - ヒアリング中・答え合わせ中は、人間から明確な **「GOサイン（よし、それで進めて！／作って！／OK！）」** が出るまで、ファイルの書き換え（`write_file` / `edit_file`）やコマンド実行（`run_command`）を一切行わない。
  - ただし、開発者本人（Shinji）が「ターボモードでそのまま実装・プッシュしろ」と直接GOサインを出している作業については、即座に実行する。

## 2. スラッシュコマンド一覧（`/` でリストビューから選択可能）
- **`/kiku`** （必要時に呼び出せるオンデマンド型）:
  - 現在の要望について、専門用語ゼロの「徹底ヒアリング＆人間とAIの答え合わせ」を開始し、GOサインが出るまで実装をストップする。
- **`/kiku-on`** （常駐モード切り替え・確認型）:
  - 会話全体に「常駐ヒアリング＆GOサイン待機ロック」を適用し、毎回の変更前に必ずやさしい言葉での答え合わせとGOサイン確認を挟む。
