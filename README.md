## 1. Overview (概要)

**Kiku (`kiku-package`)** is a Google Antigravity plugin designed for non-programmers, beginners, and accessibility-focused pair programming who do not know technical jargon such as `Kotlin`, `Git`, `PowerShell`, `Activity`, or terminal commands.

Instead of artificially transpiling or "laundering" source code into pseudo-languages, **Kiku preserves 100% authentic, original source code (such as native Kotlin)** in the background while transforming the human-AI interface into a **Zero-Jargon, Empathy-First Interview & Alignment Loop**.

The AI agent asks gentle, one-by-one questions in plain everyday language, verifies mutual understanding ("Answer-Checking / 答え合わせ"), and **strictly locks all file edits and command executions until the human explicitly gives the "GO" sign**.

---

## 2. Included Slash Commands (同梱スキル)

Type `/` in the Antigravity chat input box to select either skill from the list view:

| Slash Command | Mode | Description |
| :--- | :--- | :--- |
| **`/kiku`** | **On-Demand Mode (必要時呼び出し型)** | Launches an interactive, zero-jargon hearing session for the current request. Blocks all code changes and command executions until the user is 100% satisfied and gives an explicit GO sign. |
| **`/kiku-on`** | **Always-On Resident Mode (常駐型)** | Activates a persistent workspace-wide guard that enforces zero-jargon interviewing, human-AI alignment, and pre-implementation GO-sign locking across the entire conversation. |

## 3. Installation (インストール方法)

### Install via Antigravity CLI (`agy`)
```bash
agy plugin install https://github.com/shinji5683/kiku-package
```

### Install in Workspace (`.agents/plugins/`)
Clone or copy into `.agents/plugins/kiku-package` inside your project root.
